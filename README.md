<h3>Experience</h3>

Site Reliability / DevOps Engineer with **4.5+ years** building and operating cloud-native production systems, including **real-time trading and financial-services** infrastructure and **multi-tenant SaaS**. Specialized in **AWS, Kubernetes, Terraform, and CI/CD**, with a track record of reducing MTTR, cutting infra cost, and automating operational work.

**Ventura Securities** (Jun 2026 – Present) — Assistant Manager, DevOps Engineering. Own AWS, nginx routing, and CloudFront for a ~30-microservice trading stack (C++ / Node.js, Flutter) at a brokerage operating since 1994. Fixed a production/DR nginx region mismatch, cut latency by moving static images to CloudFront, and run Jenkins / GitHub Actions pipelines with rolling and blue-green production deploys.

**CloudBees** (2024 – 2026) — Site Reliability Engineer. Provisioned AWS EKS for 3+ production SaaS environments (single-tenant and multi-tenant). Terraform and CloudBees Unify cut deployment time ~30%. Led zero-downtime EKS v1.34 upgrades and Amazon Linux 2023 node groups. GitHub Actions and Tekton for daily deploys; Helm, Helmfile, and Karpenter for 30+ apps. Datadog SLA/SLO dashboards and EKS log filtering — 99.9% observability and ~10% cost reduction. Lambda + SQS incident routing cut alert noise ~60%. Vault for secrets; Cassandra, RDS, and OpenSearch right-sizing (~15% cost). On-call; ~20% lower MTTR via runbooks.

**Media.net** (2022 – 2023) — DevOps Engineer. 80+ Proxmox hosts and 100+ VMs at 99.9% uptime. Puppet, Bash, and Python for provisioning. Prometheus and Icinga2 for faster detection. Jenkins, GitLab, and Argo CD for Kubernetes. Linux/Windows, networking, RCA.

Also: migrated AWS Terraform (HCL) to Go-based tooling with AWS SDKs; Datadog RUM and SLI/SLO observability with event correlation.
